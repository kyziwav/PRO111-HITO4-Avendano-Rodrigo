# PRO111-HITO4-Avenda-o-Rodrigo
## Control de Asistencia y Rendimiento Académico
### Descripción
Este proyecto permite registrar estudiantes de una academia de capacitación, calcular su porcentaje de asistencia, determinar su condición académica y generar un resumen final del curso.
### Requisitos
* Python 3.10 o superior.
### Ejecución
1. Descargar o clonar el repositorio.
2. Abrir una terminal.
3. Ubicarse en la carpeta del proyecto.
4. Ejecutar:
python main.py
